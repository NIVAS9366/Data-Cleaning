# 🧹 Data Cleaning & Reporting Automation

An automated data pipeline built in Python to ingest raw, messy datasets, clean missing and duplicate values, standardize text formatting, calculate business metrics, and generate automated visual summary reports[cite: 5].

---

## 📌 Project Overview
Data preprocessing typically consumes a significant portion of a data analyst's workflow. This project automates the entire ingestion-to-visualization pipeline, ensuring data integrity and producing production-ready outputs[cite: 5].

---

## 🎯 Key Features & Workflow
* **Duplicate Removal:** Automatically detects and drops redundant duplicate rows[cite: 5].
* **Text Standardization:** Cleans erratic whitespace and normalizes client naming conventions[cite: 5].
* **Missing Value Imputation:** Safely fills missing values using statistical medians[cite: 5].
* **Financial Calculations:** Computes Profit and Profit Margin securely without division errors[cite: 5].
* **Visual Summaries & Reporting:** Generates automated bar charts (`automated_visual_summary.png`) and summary statistics, exporting a clean CSV report (`automated_cleaned_report.csv`)[cite: 5].

---

## 🚀 How to Run
1. Open Google Colab and paste the updated automation script.
2. Run the cell to execute the data cleaning pipeline and generate the plot.
3. Download `automated_cleaned_report.csv` and `automated_visual_summary.png` from your file explorer.
